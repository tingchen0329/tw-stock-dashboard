# 台股深度分析報告（v2.0）

## 原則
- **每個數字都要有來源**：只能使用 `scripts/summarize.mjs` 輸出、或 `/finmind` 指令實際查到的資料。
- 查不到就寫「N/A（資料不足）」，**絕不憑記憶推測**價格、利率、指數、EPS。
- 不使用 emoji、不使用「噴發、狂飆、亮眼」等情緒詞；用數字說話。
- 結尾一定提醒：資料整理與研究參考，非投資建議。

## 步驟

### 1. 取得資料（擇一）
```bash
# A. 已有本機資料（scripts/preview.sh --live 產生）或設定了 FINMIND_TOKEN
node scripts/summarize.mjs <代號或名稱> --prompt     # 完整分析指令＋所有數據
node scripts/summarize.mjs <代號或名稱>              # JSON 摘要（要自己組報告時用）
```
- 若出現「FinMind 額度已用完」或 token 未設定：告訴使用者 `export FINMIND_TOKEN=...`（不要要求使用者把 token 貼進對話）。
- 需要 summarize 沒有的資料（例如股利政策、借券、期貨），改用 `/finmind <自然語言查詢>`。

### 2. 單檔（1–4 檔）：七段報告
依 `--prompt` 輸出最後的「請依下列結構輸出」撰寫：
1. 開頭：資料截止日、缺少的項目（照 completeness.missing 列出）
2. 總體經濟背景（只用輸出中的總經數字；景氣燈號 / PMI 沒有就寫 N/A）
3. 股價表現與相對強弱（5/20/60 日、YTD、一年、價格位階）
4. 基本面（月營收年增、近四季 EPS、三率與去年同期、ROE、負債比）
5. 籌碼面（法人當日 / 5 日 / 20 日、外資連續、外資持股、融資券、券資比）
6. 技術面（均線排列、KD、RSI、MACD、量比、20/60 日與 52 週高低）
7. 本益比河流圖（目前倍數、百分位、區間、25/50/75 百分位對應價）
8. 綜合結論表格：投資評級、操作週期、第一買點 / 第二加碼點 / 停損點、合理估值區間、三大優勢、三大風險、壓力測試、追蹤指標
   - 買點與停損要對應到具體依據（例如「MA60 xxx 與 60 日低點 xxx 之間」「河流圖 25 百分位 xxx」）
9. 分析師自我檢查（哪些來自資料、哪些推估、哪些主觀、最該再驗證的 3 個數字）

### 3. 批次（5 檔以上）
1. 每檔跑 `node scripts/summarize.mjs <代號>`，整理成篩選表：
   代號｜名稱｜產業｜資料日期｜股價｜PE｜PB｜ROE｜負債比｜近月營收年增｜20 日外資（張）｜河流圖區間｜初步評級
   - 數字保留 2 位小數；缺值寫「N/A」
2. 挑 2–3 檔做完整七段報告，並說明挑選與不挑的理由
3. 組合健檢：產業集中度（%）、高 PE（>20x）與低 PE（<12x）比例、高負債（>50%）曝險、缺少的防禦 / 金融部位，給出「核心–衛星–觀察」分群

### 4. 輸出
- 預設直接在對話中輸出 Markdown。
- 使用者要求存檔時寫到 `reports/<YYYY-MM-DD>-<代號>.md`（reports/ 已在 .gitignore 之外，可選擇是否 commit）。
